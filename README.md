# 🪙 HiloCoinBot

ربات ایردراپ تلگرام با **Mini App**، سیستم رفرال کامل و **پنل مدیریت**.
هر کاربر به محض ورود **۱۰۰۰ دلار** جایزه خوش‌آمدگویی می‌گیرد (قابل تغییر از پنل).

---

## ⚡ نصب با یک دستور

روی یک سرور **Ubuntu یا Debian** (مثلاً یک VPS) این دستور را اجرا کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/miladgiotin074/HiloCoinBot/main/install.sh -o install.sh && sudo bash install.sh
```

اسکریپت چند سؤال ساده می‌پرسد و بقیه کارها را خودش انجام می‌دهد:

| سؤال | توضیح |
|---|---|
| توکن ربات | از [@BotFather](https://t.me/BotFather) با دستور `/newbot` بگیرید — اسکریپت درستی آن را بررسی می‌کند |
| دامنه | دامنه یا ساب‌دامنه‌ای که رکورد A آن به IP سرور اشاره می‌کند. **اگر دامنه ندارید خالی بگذارید** تا آدرس رایگان `IP.sslip.io` استفاده شود |
| آیدی ادمین | آیدی عددی تلگرام شما (از [@userinfobot](https://t.me/userinfobot)) — اختیاری |
| رمز پنل مدیریت | خالی بگذارید تا یک رمز قوی ساخته شود |
| ایمیل | برای اطلاع از انقضای SSL — اختیاری |

**کارهایی که اسکریپت انجام می‌دهد:**
- نصب Node.js 22، Nginx، Certbot و Git
- دانلود ربات در `/opt/hilocoinbot` و نصب وابستگی‌ها
- ساخت فایل `.env` با تنظیمات شما
- گرفتن **گواهی SSL رایگان** (Let's Encrypt) و تمدید خودکار آن
- اجرای ربات به‌صورت سرویس سیستمی که بعد از ری‌استارت سرور هم خودکار بالا می‌آید
- باز کردن پورت‌های 80 و 443 در فایروال (اگر ufw فعال باشد)
- در پایان، لینک ربات، آدرس مینی‌اپ، آدرس پنل مدیریت و رمز آن را نمایش می‌دهد

**نصب بدون سؤال** (مثلاً برای اسکریپت‌نویسی):
```bash
sudo BOT_TOKEN=123:ABC DOMAIN=bot.example.com ADMIN_IDS=111111 bash install.sh
```

### 🛠 مدیریت ربات روی سرور

بعد از نصب، دستور `hilocoin` در دسترس است:

| دستور | کار |
|---|---|
| `hilocoin status` | وضعیت ربات |
| `hilocoin logs` | مشاهده لاگ زنده (خروج با Ctrl+C) |
| `hilocoin restart` | ری‌استارت ربات |
| `hilocoin update` | دریافت آخرین نسخه از گیت‌هاب و ری‌استارت (تنظیمات و دیتابیس حفظ می‌شوند) |
| `hilocoin config` | تغییر توکن، دامنه یا تنظیمات ادمین |
| `hilocoin backup` | ذخیره نسخه پشتیبان دیتابیس در `/opt/hilocoinbot/backups` |
| `hilocoin stop` / `start` | توقف / شروع |

> سرور باید به `api.telegram.org` دسترسی داشته باشد؛ اگر تلگرام در کشور سرور فیلتر است، از سروری در کشور دیگر استفاده کنید.

## 📋 بعد از نصب

1. وارد پنل مدیریت شوید: `https://دامنه-شما/admin/`
2. در بخش **تسک‌ها**، ۴ تسک نمونه با لینک‌های موقت ساخته شده‌اند — لینک‌ها را با کانال و صفحات خودتان عوض کنید.
3. برای تسک «عضویت در کانال»: نوع را **تلگرام** بگذارید و ربات را در کانال **ادمین** کنید تا عضویت خودکار بررسی شود.
4. در **تنظیمات**، لینک کانال رسمی، نام توکن و متن ایردراپ را تنظیم کنید.
5. (اختیاری) در BotFather: `Bot Settings → Configure Mini App → Enable Mini App` و آدرس سایت را وارد کنید. دکمه منوی ربات خودکار تنظیم می‌شود.

## 💻 اجرای دستی (کامپیوتر خودتان یا سرور غیر Ubuntu)

پیش‌نیاز: Node.js نسخه **22 یا بالاتر**

```bash
git clone https://github.com/miladgiotin074/HiloCoinBot.git
```
```bash
cd HiloCoinBot && npm install
```
```bash
cp .env.example .env
```
فایل `.env` را پر کنید:

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از BotFather |
| `WEBAPP_URL` | آدرس https سرور شما (بدون `/` در انتها) |
| `ADMIN_PASSWORD` | رمز پنل مدیریت — حتماً یک رمز طولانی و تصادفی |
| `ADMIN_IDS` | آیدی عددی تلگرام ادمین‌ها (با کاما جدا) |
| `PORT` | پورت سرور (پیش‌فرض 3000) |
| `BOT_MODE` | `polling` (پیش‌فرض) یا `webhook` |

```bash
npm start
```

**آدرس https موقت برای تست:** با `npx cloudflared tunnel --url http://localhost:3000` یا `ngrok http 3000` یک آدرس بگیرید، در `WEBAPP_URL` بگذارید و سرور را ری‌استارت کنید.

**تست در مرورگر معمولی (بدون تلگرام):** در `.env` مقدار `DEV_MODE=true` بگذارید و `http://localhost:3000/?dev_user=123` را باز کنید (برای تست رفرال: `?dev_user=456&start=ref_123`).

> ⚠️ **هرگز** `DEV_MODE` را روی سرور اصلی روشن نکنید؛ با آن هر کسی می‌تواند جای هر کاربری وارد شود.

## 🔒 امنیت
- هر درخواست مینی‌اپ با امضای `initData` تلگرام (HMAC با توکن ربات) اعتبارسنجی می‌شود؛ کاربر نمی‌تواند هویت جعلی بسازد.
- همه برداشت‌ها (روزانه، ماینینگ، تسک، جوایز پله‌ای) سمت سرور و به‌صورت اتمیک بررسی می‌شوند تا دوبار دریافت نشوند.
- محدودیت تعداد درخواست برای هر کاربر و محدودیت تلاش ورود به پنل مدیریت وجود دارد.
- خودِ معرف نمی‌تواند با لینک خودش عضو شود و هر کاربر فقط یک‌بار (در اولین ورود) ثبت رفرال می‌شود.
- هر آدرس کیف پول فقط به یک حساب تعلق می‌گیرد.
- فایل `.env` و دیتابیس هرگز در گیت آپلود نمی‌شوند (`.gitignore`).

> 💡 موجودی کاربران امتیاز داخل اپ است. در متن ایردراپ به کاربران شفاف بگویید این موجودی دقیقاً به چه چیزی و با چه نرخی تبدیل می‌شود، و چیزی وعده ندهید که قادر به پرداختش نیستید.
